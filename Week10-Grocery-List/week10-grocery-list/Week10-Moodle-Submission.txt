Grocery list application

This HTML, CSS and JavaScript application lets users add and remove groceries. Items are displayed in a bulleted unordered list using ul and li elements.

The groceries array stores the items. push() adds an item to the end of the array. splice(index, 1) removes the selected item. Unlike pop(), which removes only the last element, splice() can remove an item at any position.

A submit handler adds an item when the Add item button is clicked or Enter is pressed. A click handler on each Remove button removes that item. displayGroceries() uses a loop and DOM manipulation to rebuild the list from the array. Blank entries are rejected and surrounding spaces are removed. The list resets when the page is refreshed.
